A molecule’s 3D structure, built live from its SMILES

No stored 3D file, no IPFS, no server. The SMILES string alone — a few dozen characters — goes in, and the 3D structure is generated entirely in your browser (OpenChemLib builds a conformer; 3Dmol renders it). For small molecules this is the most efficient thing you can put on-chain: store the SMILES (often shorter than an IPFS CID) and rebuild the molecule on demand.
Why this matters for MolNFT: a ligand’s SMILES is ~20–60 bytes and self-contained — commit it on-chain and every client can regenerate the 3D with zero external dependencies. (Proteins still need their PDB file on IPFS — you can’t fold a structure from data — but ligands don’t.)

The 3D shown is a generated low-energy conformer — chemically reasonable and fine for viewing, not necessarily the exact experimental geometry. Everything here runs locally; nothing is uploaded.
How it works: OpenChemLib (pure JS) parses the SMILES, adds hydrogens and generates a 3D conformer via distance geometry; 3Dmol.js renders it. Both load once from a CDN, then it’s all local. Prototype extension of the GenesisL1 aroma index — the client-side SMILES→3D path proposed for MolNFT small-molecule integration.
